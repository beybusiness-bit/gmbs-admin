GMBS Admin
앱 구조 가이드

사이드바 구성, 로그인 규칙, 페이지 패턴 등 UI 구조를 다른 프로젝트에서 참고할 수 있도록 정리한 문서입니다.

앱 개요

GMBS 소품샵의 브랜드·상품·바코드·정산을 관리하는 내부 관리자 전용 웹앱.

  • 접속 방법: Vercel 배포 URL — 특정 Google 계정으로만 로그인 가능
  • 사용자: 허가된 2개 계정만 (동일 권한, 역할 구분 없음)
  • 배포: GitHub main 브랜치 push → Vercel 프로덕션 자동 배포
  • 데이터: Firebase Firestore (프로젝트 ID: beyhome-admin)
기술 스택
📄 단일 HTML 파일

프레임워크 없음. index.html 하나에 CSS·JS·HTML 전체 포함. 빌드 과정 불필요.

🔥 Firebase v10 (ESM CDN)

Auth / Firestore / Storage / Functions. type="module" script에서 직접 import.

📦 외부 라이브러리 (CDN)

JsBarcode (바코드 생성), jsPDF (PDF), JSZip (일괄 다운로드), SheetJS (엑셀 파싱)

📱 PWA

Service Worker + manifest.json. 홈 화면 설치 가능. 오프라인 기본 캐싱.

구현 패턴
onAuthStateChanged(auth, async (user) => {
  if (!user) {
    showLoginScreen();
    return;
  }
  if (!ALLOWED_EMAILS.includes(user.email)) {
    await fbSignOut(auth);  // 즉시 로그아웃
    showToast('접근 권한이 없는 계정입니다.', 'error');
    return;
  }
  window._currentUser = user;
  showApp();
});

페이지별 데이터 정리 방법
페이지목록 구성상세 접근
브랜드카드형 그리드 — 브랜드코드 배지 + 상태 배지클릭 → 상세 모달 (담당자·계약·이력 탭)
담당자테이블형 — 브랜드별 그룹인라인 수정
승인탭(브랜드 입점 / 상품 등록) + 상태 필터클릭 → 승인/거절 처리 모달
상품상품 단위 묶음 표시 — 하위 SKU 접기/펼치기클릭 → 수정 모달
정산기간별 테이블 — 지급 상태 배지클릭 → 상세 모달
바코드상품 단위 그룹 + SKU 체크박스 — 선택 후 인쇄/다운로드라벨 미리보기 모달
문의답변 상태 필터 + 브랜드명 표시클릭 → 답변 작성 모달
안내탭(공지사항 / 안내 카드 / FAQ)인라인 편집 또는 모달
